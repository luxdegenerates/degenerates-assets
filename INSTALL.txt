DEGENERATES — HOME SCREEN ICON WORKAROUND
=========================================

WHY THIS EXISTS
---------------
Google Apps Script HtmlService can set a normal favicon with setFaviconUrl(),
but an iPhone Home Screen Web Clip expects apple-touch-icon metadata.

Apps Script ignores <link rel="apple-touch-icon"> placed in Index.html,
so the direct script.google.com /exec page cannot reliably supply the
custom Home Screen icon.

This GitHub Pages launcher provides the top-level apple-touch-icon metadata.


FILES TO UPLOAD TO THE ROOT OF degenerates-assets
--------------------------------------------------
index.html
manifest.json
degenerates-icon-180.png
degenerates-icon-192.png
degenerates-icon-512.png
degenerates-icon-1024.png


ONE EDIT REQUIRED
-----------------
Open index.html on GitHub.

Find:

const DEGENERATES_APP_URL =
  'PASTE_YOUR_COMPLETE_APPS_SCRIPT_EXEC_URL_HERE';

Replace only the text inside the quotes with the COMPLETE live /exec URL
of the DEGENERATES Apps Script website.

Example shape:

https://script.google.com/macros/s/XXXXXXXXXXXX/exec


THEN
----
1. Commit the files to the PUBLIC degenerates-assets repo.
2. Ensure GitHub Pages is enabled for main / root.
3. Open:

   https://luxdegenerates.github.io/degenerates-assets/

4. Do NOT add the script.google.com address to the Home Screen.
5. Add the GitHub Pages address above to the Home Screen.
6. The Home Screen icon comes from the 180px DEGENERATES icon.
7. When launched from the Home Screen, the launcher redirects into the
   normal Apps Script website.

If the platform opens the launcher as a normal browser tab rather than
standalone, the OPEN DEGENERATES button remains available.
